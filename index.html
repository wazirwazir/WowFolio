Audiophile E-commerce

Audiophile is a professional grade e-commerce web application built using HTML, CSS, JavaScript on the frontend and a full backend stack featuring Node.js, Express and PostgreSQL. Designed for premium audio equipment, the platform supports user sign-in, browsing of high-quality audio gear, category filtering and a managed shopping cart, all wrapped in a clean, responsive design to ensure seamless experience across devices.

Sneakers Ecommerce

The Sneakers Ecommerce website is a project that simulates an online store specializing in sneakers. It features a sleek, user-friendly design with an emphasis on showcasing various sneaker models. The site includes a homepage with promotional banners and product highlights, product pages with detailed information and images, and a shopping cart functionality. It is designed to be responsive, ensuring a seamless shopping experience across devices. Key technologies used in this project are HTML, CSS, and JavaScript.

Muse: Social Media Platform

Muse is a full-stack web application built using HTML, CSS, JavaScript for the frontend and a Node.js/Express backend with PostgreSQL as the database. It enables users to register, create profiles, post updates, like and comment on others' post, and explore a feed of social interactions all within a clean , responsive interface, optimized for seamless engagements.

Todo App

The Todo App project is a task management application designed to help users organize and manage their daily tasks efficiently. The app features functionalities such as adding, editing, and deleting tasks, as well as marking tasks as complete. It utilizes local storage to save tasks, ensuring that user data persists even after the browser is closed. With a clean and intuitive user interface, the app provides a seamless experience across different devices. Technologies used include HTML, CSS, and JavaScript.
